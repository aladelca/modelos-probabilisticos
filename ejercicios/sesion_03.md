# Ejercicios - Sesión 03

## Ejercicio 1: variables aleatorias sobre dados

Sobre el lanzamiento de dos dados define:

- $X$: suma.
- $Y$: máximo.
- $Z$: indicador de dobles.

Para cada variable:

1. Indica si es discreta o continua.
2. Construye su soporte.
3. Calcula o simula su PMF.

## Ejercicio 2: clasificación de columnas

Usa `data_sources/sales_data.csv`.

1. Clasifica cada columna como categórica, Bernoulli, conteo, continua positiva o índice temporal.
2. Propón tres variables aleatorias relevantes para un caso de inventario.
3. Indica qué información se pierde al convertir `Demand` en un indicador de demanda alta.

## Ejercicio 3: transformación

Simula una variable lognormal. Compara histograma de $X$ y de $\log X$.

Explica por qué la transformación puede facilitar un modelo normal.
